PostGIS Query: Spatial Intersection with Temporal ETA Window Index: GIST(full_route_geometry) 
SELECT 
    t.truck_id,
    at.trip_id,
    at.origin_city,
    at.destination_city,
    d.title AS disruption_event,
    d.severity
FROM active_trips at
JOIN trucks t ON at.truck_id = t.truck_id
JOIN location_disruptions d 
    ON ST_Intersects(at.full_route_geometry, d.affected_geofence)
WHERE at.status = 'ACTIVE'
  -- Temporal ETA Window Check: Only flag if arrival coincides with disruption
  AND (at.started_at + INTERVAL '12 hours') 
      BETWEEN d.start_time AND d.expected_end_time;

    checkpoint_id SERIAL PRIMARY KEY,

Deep Architectural Breakdown

How SupplyNet Solves Highway Bottlenecks

A hybrid setup designed for high-scale enterprise fleets: high-frequency GPS telemetry in Redis, spatial intersections in PostGIS, and high-speed OSRM routing driven by multi-agent LLM decisions.

01

OSRM Micro-Detours via Waypoints

Default routing engines generate statewide diversions. SupplyNet structures queries by intermediate transit nodes (Agra → Mehgaon → Jhansi) to force tight, cost-efficient bypasses around local disruptions.

02

Automated PostGIS Geofencing

Converts unstructured news, roadblock reports, and weather alerts into spatial buffer polygons (ST_Buffer(Point, 15km)). Checks ST_Intersects against trip polylines with forward ETA windowing.

03

Streamlined Multi-Agent Chain

Replaces slow 6-hop LLM chains with a 3-hop optimized architecture: Monitoring Agent → Supervisor Node → Planner Agent, backed by a deterministic Code Guardrail and Critique Evaluator.

04

Hybrid Tri-Tier Telemetry

Separates high-frequency 30-second GPS pings into in-memory Redis buffers, preventing SQL database thrashing while persisting verified checkpoints and trips to PostgreSQL with PostGIS.

05

Multi-Enterprise Tenant Isolation

Every trip, truck, checkpoint, and audit log is isolated by enterprise_id foreign keys. Multiple freight companies operate simultaneously with zero cross-tenant data leaks.

06

Weighted Cost Tradeoff Function

Detour approval is mathematically governed by: Cost = w₁·Duration + w₂·Distance + w₃·Toll Ensures fuel, driver shift hours, and toll penalties never outweigh the delay time saved.
